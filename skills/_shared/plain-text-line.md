# Plain-text line output

**Plain-text line** — each game field is one ordinary text line on its own row.

## Rule

Output every `【字段】` as a **plain-text line**. Some chat UIs (e.g. 豆包) render Markdown code blocks and `<pre>` as boxed plaintext, which breaks copying and layout.

## Applies to

- Question prompts (题面 / 方向 / 出处)
- Answer reveals (答案 / 赏析 / 得分)
- Idiom cards (成语 / 出处 / 含义 / 例句)

## Code blocks

Reserve code fences for actual code only — never wrap game fields in them.
